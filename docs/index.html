What's the difference in hand position during prayer between the madhhabs?
Hand placement (qabḍ) while standing:
• Hanafi — below the navel
• Maliki — released at the sides (sadl)
• Shafi'i — on the chest
• Hanbali — chest or below navel
Each is derived from different narrations; all valid within their schools. 📚

Why this exists

Classical fiqh, turned into a conversation.

Reliable, structured knowledge about the four madhāhib is scattered across dense classical texts that are hard to search and harder to compare. Most people don't have a scholar on speed-dial to ask "how does wudu differ between Hanafi and Shafi'i?"

How it works

From a WhatsApp message to a grounded answer.

User asks

A WhatsApp message is forwarded by WAHA to the Flask webhook.

Agent reasons

The Agentic AI decides which tools to use and queries the RAG engine.

Retrieve

Relevant passages are pulled from ChromaDB over the curated knowledge base.

Answer

Groq / Llama 3.3 composes a grounded reply, sent back with context preserved.

Quick Start

Run it yourself in minutes.

Prerequisites: Python 3.10+, a running WAHA server, and a free Groq API key.

# 1. Clone
git clone https://github.com/mshadianto/kitab-mazhab-ai.git
cd kitab-mazhab-ai

# 2. Set up environment
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Configure your keys, then run setup
cp .env.example .env
python setup.py

# 4. Run
python app.py

# Then point WAHA's webhook at http://YOUR_SERVER:5000/webhook
# and send assalamualaikum from WhatsApp 🎉
